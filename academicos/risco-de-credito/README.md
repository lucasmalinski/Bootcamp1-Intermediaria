# Warehouse de Risco de Crédito + Machine Learning

> Solução de dados ponta a ponta: ingestão bruta, Star Schema em camadas (Bronze → Analytics) e modelos preditivos de inadimplência e taxa de juros.

**Contexto:** Projeto final — Desenvolvimento para Ciência de Dados II (CEUB)

## Tecnologias

- PostgreSQL
- SQL
- Python
- Pandas
- scikit-learn
- Jupyter

## Destaques

- ELT em PostgreSQL com schemas bronze e analytics e views analíticas
- Classificação (KNN, Árvore, Random Forest, Regressão Logística): Random Forest com 93,3% de acurácia
- Regressão da taxa de juros com R² de 0,91 e recomendações de negócio orientadas a recall
