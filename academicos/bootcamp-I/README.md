# Bootcamp I — PortfolioHUB

> Este próprio repositório: um hub que organiza e documenta meus projetos acadêmicos e pessoais, versionado com Git e publicado via GitHub Pages.

**Contexto:** Bootcamp I (CEUB) — Entrega Intermediária: Criação de Repositório com Versionamento

## Tecnologias

- Git
- GitHub
- GitHub Pages
- Markdown
- HTML/CSS

## Destaques

- Estrutura de pastas por categoria (acadêmicos e pessoais) e por projeto
- README.md em cada projeto seguindo um mesmo padrão
- Página web em GitHub Pages (pasta /docs) e integração com o LinkedIn
- Versionamento com tags (v1.0 e seguintes)
