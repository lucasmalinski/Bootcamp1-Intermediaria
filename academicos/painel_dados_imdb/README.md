# Dashboard de Performance Cinematográfica (IMDB)

> Análise exploratória e financeira de mais de 33 mil filmes, focada em rentabilidade e na correlação entre crítica e premiações.

**Contexto:** Disciplina de BI (UniCEUB)

## Tecnologias

- Power BI
- Power Query (M)
- DAX

## Destaques

- ETL passo a passo documentado em script M
- Perguntas de negócio: rentabilidade por país, nota IMDB × Oscar, receita por gênero
- Painel publicado no Power BI Service
