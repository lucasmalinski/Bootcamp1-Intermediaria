# YAHT — Yet Another Habit Tracker

> Tracker de hábitos minimalista em linha de comando, com registro diário e histórico salvo localmente em JSON.

**Contexto:** Bootcamp II — Prof. Dr. Romes Heriberto

## Tecnologias

- Python
- JSON
- unittest
- ruff
- GitHub Actions

## Destaques

- Hábitos configuráveis em um arquivo de texto
- Testes automatizados com unittest e linting com ruff
- CI no GitHub Actions e versionamento semântico (v1.2.0)
