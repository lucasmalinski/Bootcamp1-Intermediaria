# CVM Extractor

> Aplicação web que automatiza a extração e a visualização dos dados de composição de carteiras (CDA) de fundos de investimento publicados pela CVM.

**Contexto:** Projeto final do CS50x (Harvard)

## Tecnologias

- Python
- Flask
- Pandas
- Bootstrap
- DataTables

## Destaques

- ETL em memória: download dos ZIPs da CVM e parsing dos CSVs fora do padrão
- Interface com tabela interativa, busca e exportação para CSV e Excel
- Migração de protótipo desktop (Tkinter) para web (Flask), com deploy no Render
