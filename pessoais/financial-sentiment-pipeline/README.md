# Financial Sentiment Pipeline

> Pipeline que coleta notícias de cripto do Yahoo Finance a cada meia hora e as acumula em CSV sem duplicatas.

**Contexto:** Projeto pessoal

## Tecnologias

- Python
- BeautifulSoup4
- Pandas
- dateparser
- GitHub Actions

## Destaques

- Web scraping com User-Agent customizado e parsing com BeautifulSoup
- Conversão de datas relativas ("2 hours ago") para timestamps
- Execução agendada 24/7 via GitHub Actions
