# BanVic — Pipeline de Dados

> Pipeline de engenharia de dados que extrai de CSV e de PostgreSQL, passa por um data lake local e carrega em um data warehouse.

**Contexto:** Desafio técnico do processo seletivo Indicium Lighthouse

## Tecnologias

- Airflow
- Meltano
- Docker
- PostgreSQL

## Destaques

- Orquestração diária no Airflow com DockerOperator
- Extração com Meltano e taps customizados
- Quatro ambientes Docker isolados simulando a arquitetura real
