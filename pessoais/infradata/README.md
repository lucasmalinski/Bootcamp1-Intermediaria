# Infradata

> Pacote Python com pipeline de dados geoespaciais de infrações e fluxo de tráfego, organizado em camadas raw → silver.

**Contexto:** Projeto pessoal

## Tecnologias

- Python
- Conda
- GeoPandas

## Destaques

- Ambiente reproduzível com Conda (conda-forge) e pacote local instalável
- Pipeline principal executável via script
- Separação entre dados brutos, caches externos e saída processada
